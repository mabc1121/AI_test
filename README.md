# Paper Trading Research Template

A paper-only BTCUSD research platform: **Trade** (a strategy on live verified market data with a protected paper
broker), **Think / Lab** (independent AI seats that research, build, test and evaluate strategy changes),
**Supervisor** (the agent you talk to; every change is a proposal you approve) and a private **UI**.
One template, many apps: install a copy per strategy with `deploy/install_app.sh`.
